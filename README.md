# CSS Lab — Week 1 Task 3

A responsive CSS challenge project using a orange, mint, and navy color palette, demonstrating the three exercises required in the Week 1 assignment.

## Exercises included
1. **Flexbox layout:** Three testimonial cards in a row on desktop and stacked on small screens, with hover effects.
2. **CSS Grid layout:** A six-item responsive gallery using CSS Grid.
3. **Animation:** Smooth hover transitions, a small animated progress bar, floating decorations, and an interactive button.

## Tech stack
- HTML5
- CSS3 (Flexbox, Grid, media queries, transitions, keyframes)
- Vanilla JavaScript for the mobile menu and demo button interaction

## How to run
1. Download or extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.
3. Resize the browser to test mobile responsiveness.

## Files
- `index.html` — page structure and content
- `style.css` — styling, responsive layouts, and animations
- `script.js` — mobile navigation and demo button interaction
